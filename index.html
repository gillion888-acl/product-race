为什么开这一轮

上一轮三匹马都落在教育场景——那是被第一个分析对象锚定的结果。这一轮刻意换成校园之外、买方更具体的场景，用来检验「痛感强度」与「决策链长度」对成不成得了生意的影响。

维度权重看什么

04怎么审核这些产品

  1. 打开任意产品的在线体验，点首屏那颗主按钮（每个产品都有「用示例数据试一次」），十秒内能看到核心价值。
  2. 看它的常见问题与已知限制——每个产品都在 README 里主动写了自己的边界与做不到的事。
  3. 读 pitch.md（一页商业论证）：目标客户、替代做法与成本、定价、第一单怎么拿。
  4. 读 SCORECARD.md：这份看板上每一匹马的九维度得分与依据。
所有产品均为独立实作，未包含任何第三方产品的代码或素材；示例资料与文档模板为原创内容。 产品文档与界面为简体中文。评分与审核由产品负责人执行。
